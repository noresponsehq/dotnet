# NoResponse .NET SDK

The official .NET client for the [NoResponse](https://noresponse.org) API: a risk assessment for each signup, login, recovery or profile change, with a 0 to 100 score, the reasons and a recommendation.

This SDK is in preparation and will be published to NuGet. Until then, call the API directly with any HTTP client; the full reference, with a playground, is at [docs.noresponse.org](https://docs.noresponse.org). The Node, Python and Go SDKs are available now.
