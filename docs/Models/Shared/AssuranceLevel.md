# AssuranceLevel

Provider or OIDC assurance level, when the customer has mapped one.

## Example Usage

```csharp
using NoResponse.Models.Shared;

var value = AssuranceLevel.Unknown;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `Unknown` | unknown   |
| `Low`     | low       |
| `Medium`  | medium    |
| `High`    | high      |
